# TaskTracker
this is a project for roadmap.sh and it is about TaskTracker with Go

# How To Run
you just have to build it with : 
> go build -o ./bin/task-cli  .

and then run it with 
> cd bin
> ./task-cli

# Roadmap Project URL
the url for this project in Roadmap is : https://roadmap.sh/projects/task-tracker
